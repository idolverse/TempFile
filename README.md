# 📁 にゃ～这里是临时文件夹喵！

呐呐呐！这里是一个专门用来放临时文件的地方喵～🐾  
什么构建缓存啦、Unity自动生成的文件啦、测试脚本啦，都可以悄悄藏在这里喵，不要让主线代码变得脏脏的 >///<

---

## 🌸 用途说明喵：

- 🧪 放一些还在试验阶段的脚本、代码碎片
- 🏗️ Unity/ROS2 构建中间产物也可以先藏在这里
- 📦 自动生成的 `.json`、`.launch.xml`、`.meta` 文件也许不太重要，就不要 commit 它们啦喵～

---

## ❌ 不建议：

- 不要把这里的内容加入 Git 版本管理（会被 `.gitignore` 喵掉掉！）
- 不要在这里写重要文档或正式代码哟～会迷路的 =w=

---

## ✅ 建议做法喵：

- 每次 push 之前看一下有没有临时文件还没删（比如 `test.py.bak` 之类的）
- 可以在 `.gitignore` 中添加本目录来自动忽略
- 如果你真的超喜欢这里，也可以把它设成你的专属草稿区喵！
